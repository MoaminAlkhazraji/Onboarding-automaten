# Hur ITIL kan användas i onboarding-projektet

## Vad är ITIL?

ITIL är ett ramverk med olika arbetssätt och rekommendationer som hjälper organisationer att skapa och förbättra IT-tjänster. Syftet är att arbeta mer strukturerat, minska risker och skapa bättre värde för användarna.

I vårt onboarding-projekt finns flera ITIL-practices som passar bra att använda.

---

## 📈 Continual Improvement

### Vad är det?

Continual Improvement handlar om att hela tiden försöka göra saker bättre.

### Hur kan vi använda det?

- Gå igenom och förbättra koden innan den mergas.
- Använda spikes för att hitta förbättringar och utveckla befintlig kod.
- Diskutera vad som kan bli bättre under Sprint Retrospectives.
- Rätta buggar och förbättra lösningen under projektets gång.

---

## 📚 Knowledge Management

### Vad är det?

Knowledge Management handlar om att samla och dela information så att alla i gruppen har tillgång till den.

### Hur kan vi använda det?

- Dokumentera projektet i GitHub.
- Skriva Daily Standups, Sprint Reviews och Sprint Retrospectives.
- Uppdatera README och övrig dokumentation.
- Gå igenom kod tillsammans och dela kunskap inom gruppen.

---

## 🔄 Change Enablement

### Vad är det?

Change Enablement handlar om att planera och genomföra förändringar på ett kontrollerat sätt.

### Hur kan vi använda det?

- Använda ADKAR som stöd i förändringsarbetet.
- Planera hur den nya onboarding-processen ska införas.
- Hjälpa HR att förstå det nya arbetssättet.
- Testa förändringar innan de införs.

---

## 💻 Software Development and Management

### Vad är det?

Software Development and Management handlar om att utveckla, testa och underhålla programvara på ett strukturerat sätt.

### Hur kan vi använda det?

- Utveckla onboarding-skriptet i PowerShell.
- Använda GitHub för versionshantering och samarbete.
- Arbeta i egna branches och använda Pull Requests innan merge.
- Testa funktioner innan de läggs till i projektet.

---

## 🚀 Deployment Management

### Vad är det?

Deployment Management handlar om att införa nya lösningar på ett planerat och säkert sätt.

### Hur kan vi använda det?

- Testa onboarding-skriptet i labbmiljön innan det används.
- Säkerställa att nya funktioner fungerar innan de mergas.
- Planera hur lösningen ska användas när den är färdig.

---

## ⚠️ Incident Management

### Vad är det?

Incident Management handlar om att snabbt hitta och lösa problem som uppstår.

### Hur kan vi använda det?

- Använda loggning för att upptäcka fel.
- Felsöka och rätta buggar när de uppstår.
- Testa lösningen för att hitta problem innan den används.
