# Förändringsledning (ADKAR)

## Awareness
Efter att en enkät genomförts har det framkommit att många medarbetare inte trivs i arbetsmiljön. För att skapa medvetenhet behöver ledningen kommunicera resultaten och förklara vilka problem som finns. Genom dialogmöten och frågestunder kan medarbetarna få möjlighet att uttrycka sina tankar och funderingar kring situationen. Ett område som identifierats är att HR lägger mycket tid på manuella administrativa uppgifter, vilket kan skapa stress och ineffektiva arbetsprocesser. Därför undersöker organisationen möjligheten att införa en onboarding-automat som kan förenkla delar av arbetet.

## Desire
För att medarbetarna ska vilja delta i förändringsarbetet behöver de känna att deras åsikter värdesätts och att de kan påverka resultatet. Genom att involvera dem i diskussioner, workshops och beslut kring förbättringsåtgärder skapas ett större engagemang. När medarbetarna ser att deras feedback från enkäten leder till konkreta åtgärder ökar motivationen att bidra till förändringen. Det är också viktigt att tydliggöra vilka positiva effekter förbättringarna kan ge, såsom minskad stress, bättre samarbete och ökad trivsel på arbetsplatsen. För HR innebär detta utbildning i hur onboarding-automaten fungerar och hur information om nyanställda hanteras i systemet. Samtidigt behöver hela organisationen informeras om de förändringar som genomförs för att skapa en bättre arbetsmiljö.
